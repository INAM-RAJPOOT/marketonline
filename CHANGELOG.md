# Changelog

## 1.2.0 — 2026-10-30

### Added
- Storefront features for the theme checklist: quick view, recently viewed, stock counter, volume pricing, quick order, back-in-stock alerts, contact form, age verifier, promo popup, countdown, promo tiles, press coverage, lookbook hotspots, and before/after slider
- Cart notes, gift wrapping, pre-order labeling, and a fuller in-store pickup list
- Collection infinite scroll, swatch filters, and collection navigation
- Product tabs for shipping, ingredients, nutrition, and usage, plus a size chart
- Account menu with the shopify-account component and Sign in with Shop
- Italian, German, and Spanish locales, and right-to-left layout for RTL languages
- Image rollover, product badges, sticky header setting, back to top, and scroll animations

## 1.1.1 — 2026-10-28

### Changed
- Theme and project renamed to **MarketOnline**

## 1.1.0 — 2026-06-08

### Added
- Wishlist (localStorage, header icon, wishlist page template)
- Product reviews (standard metafields, Judge.me, app blocks)
- Checkout UI extensions app (`my-checkout-app`)
- FAQ, logo list, featured blog sections
- Breadcrumbs, structured data, price snippet
- Customer account templates and localization
- Mega menu, AJAX collection filters, product media gallery

### Improved
- Accessibility: focus return, mobile menu keyboard, carousel announcements
- Demo homepage with FAQ section
- Theme settings defaults in `settings_data.json`
- Complete French locale file

### Fixed
- Liquid `image_tag` syntax in product media and logo list
- Account link aria-label in header

## 1.0.0 — Initial release

- Cart drawer, quick add, sticky ATC, search modal
- Core templates and marketing sections
